# LongMemEval Inspector

This repository contains an indexed version of the [LongMemEval benchmark dataset](https://github.com/Bingsu-Org/LongMemEval) with visualization tools for debugging purposes.

## Purpose

The LongMemEval benchmark dataset is large and complex, making it difficult to debug and inspect directly. This repository provides:

- An indexed version of the dataset for easier navigation
- Visualization tools to help understand and debug the benchmark data
- A more accessible way to explore the dataset structure and contents

## Usage

Open `inspector.html` to visualize and explore the indexed LongMemEval benchmark dataset.

## Why This Exists

Due to the size and complexity of the LongMemEval dataset, traditional debugging methods are impractical. This inspector tool makes it easier to:
- Navigate through the large dataset
- Identify issues or patterns in the data
- Understand the structure and content of benchmark examples
- Debug problems in model evaluations
